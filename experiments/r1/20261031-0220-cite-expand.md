# cite_expand.py (POLIGON) on the submission: not applied

rockets/poligon/cite_expand.py adds, after the run, the pack session sharing the most question words with the
question when it shares >= 0.8 times as many as the best cited one (answers untouched).

1. Reactor calibration (39 dev questions, new prompt, 35 answerable; experiments/r1/cite_cmp.py):

| | evidence F1 |
|---|---|
| final-line citations | 0.795 |
| + reply fallback (ask.py, in the final run) | 0.910 |
| + fallback + cite_expand | 0.955 (ss-assistant 1.000 -> 0.944; k-update 0.810 -> 1.000) |

2. POLIGON's simulation (reader cites the gold session in the pack with most question words; then cite_expand's
rule) on the FINAL R1 packs (runs/r1/20261031-0200-fee061f-final-*; experiments/r1/cite_sim.py), 398 answerable:

| type | dev | dev-hard v2 | dev-hard-long |
|---|---|---|---|
| knowledge-update | 0.667 -> 0.868 | 0.667 -> 0.784 | 0.667 -> 0.793 |
| multi-session | 0.587 -> 0.652 | 0.587 -> 0.533 | 0.580 -> 0.530 |
| single-session-assistant | 1.000 -> 0.933 | 1.000 -> 0.893 | 1.000 -> 0.881 |
| single-session-user | 1.000 -> 0.967 | 1.000 -> 0.791 | 1.000 -> 0.797 |
| temporal-reasoning | 0.664 -> 0.721 | 0.645 -> 0.558 | 0.645 -> 0.558 |
| all | 0.765 -> 0.805 | 0.760 -> 0.690 | 0.758 -> 0.689 |

Decision: not applied to ship/predictions.jsonl. Near-miss sessions share the most question words by
construction; on test-like data (near misses, 200 sessions) the rule costs ~7 points of evidence F1. Only
knowledge-update gains, and no reliable router finds those questions.
