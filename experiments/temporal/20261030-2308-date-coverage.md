## 1. Coverage (no model, CPU)

`python experiments/temporal/coverage.py ../data/dev ../data/test`: broad date-like phrases in user turns; a phrase
counts as tagged when a `[YYYY-MM-DD, day N]` tag follows it. dev = gold sessions of the 107 non-holdout
temporal-reasoning questions; test = all user turns of all test histories.

| split | before tagged | after tagged |
|---|---|---|
| dev temporal gold sessions | 234 / 410 (57.1%) | 353 / 408 (86.5%) |
| test, all user turns | 1214 / 3259 (37.3%) | 2187 / 3251 (67.3%) |

Top misses before (dev / test): last month 21/109, this weekend 14/154, a month ago 13/23, last week 10/122,
last weekend 9/91, next month 9/64, a few weeks ago 9/23, the 15th 8, 3/22 7, on Saturday/Sunday/...
What is still untagged after, on purpose: habits ("on Sundays", "every Saturday morning", "Tuesday to Saturday"),
bare weekdays with no preposition ("coming over Sunday"), "this week/month/year", seasons, holidays
("Black Friday"), "on the 15th" with no month in the sentence, ordinals that are not dates ("36th minute").

Precision (hand check of ~200 random new tags on dev and test): explicit dates, ranges, "N days/weeks ago",
"last/this/next weekend", "last X": no errors seen. Weekdays after "on" depend on tense guessing: about 4 clear
errors in 40 ("Big family dinner on Saturday" with no verb -> past; "a rescheduled session on Saturday" -> past).
Vague ones are tagged "about" (last week, last month, a few weeks ago, N months/years ago, next weekend).

Fixed wrong tags: the year across the new year (before, a date without a year always got the session's year:
"I went skiing on December 28th" in a January session -> the coming December, "my trip is on January 10" in a
December session -> the past January; now past sentences take the latest such date up to 60 days after the
session, future ones the earliest from 60 days before, the rest the nearest); "the 20th to the 27th of April"
tagged only the 27th; patterns run one after another could tag inside an earlier tag (now one pass, longest match).
